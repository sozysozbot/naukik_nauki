# ナウキ運び

『ナウキ運び』は、手札で荷物（カードの役）を作り、木箱に積んで港へ運び、手に入れた「塩」を地元へ持ち帰って得点を競うすごろく風カードゲームです。

* **プレイ人数:** 2〜4人
* **プレイ時間:** 21.8〜29分
* **勝利条件:** いずれかのプレイヤーが地元で累計 **20点以上** を獲得したラウンドでゲーム終了。最も得点が高いプレイヤーの勝利です。

---

## 1. 内容物
 * ルートボード 6枚（地元、街道、会所、問屋、街道、港）
 * 商品カード 60枚（3品目 × 1–5等級 × 各4枚 / 1・5等級は塩2個、2–4等級は塩1個）
 * 木箱タイル 8枚（各自2枚 / 裏面は大箱）
 * 商人コマ 4個
 * 塩トークン
（図を追加）

## 2. 準備
### コース配置：
ルートボード6枚を直線に並べる。
   （図：ボード6枚の並び順と、往路0–5・復路6–10の矢印）
### 市場：
各マスの市場スペースに山札からカードを1枚ずつ表向きで置く。
### 個人準備：
   * コマを「地元」に置く。
   * 山札から手札5枚を引く。
   * 木箱タイル2枚を受け取り、片方に初期塩2個を置く（もう片方は空）。
     （図：手元配置／手札5枚・通常木箱2枚・片方に塩2個）
### スタートプレイヤーを決める。

## 3. 手番の流れ
毎手番、ステップ1（必須）、ステップ2（任意）を順に行う。

（図：ステップ1［移動➜補充］ ➜ ステップ2［荷積み／施設利用］のフローチャート）

※山札が尽きたら捨て札をシャッフルする。捨て札もない場合、全市場のカードをシャッフルして山札にする。

### ステップ1：移動と補充（必須）

#### 移動：
手札1枚を「移動元の市場」へ表向きで置く。
その数字分コマを進める。
（図：カードを移動元市場に置き、その数字分進むコマの動き）

#### 補充：
「着地マスの市場」からカード1枚を手札に加える（市場にカードがない場合は山札から引く）。

#### 手札整理：
地元に着地または通過した際、手札が6枚以上あれば5枚になるまで選んで捨てる。
   
### ステップ2：アクション（任意）
着地マスで以下を任意の順序で行う。

#### 荷積み（空箱がある限り何度でも）：
手札から役を作り、その役を空箱に乗せる。
* 連番：同じ品目で連続する3数字
* セット：同じ品目で同じ3数字
（図：役の例／連番［布2-3-4］とセット［茶3-3-3］）
* 荷積み後、着地マスの市場（不足時は山札）から手札を3枚補充する。

#### 施設利用（1回まで）：
* 着地マスの施設効果を使う。
  
## 4. 施設一覧
※塩の支払いは、木箱の上の塩のみ使用可能（手元の塩は使用不可）。

### 地元
* 換金（着地時のみ）：木箱の塩を手元に移す（塩1個＝1点）。2箱同時可。換金しない箱があってもよい（※通過時は不可）。

### 会所
* 木箱の塩2個を支払い、木箱1枚を裏返して「大箱」にする。

### 問屋
* 仕入れ：追加でカード1枚を獲得する。さらに木箱の塩1個を支払うごとに、追加でカード1枚を獲得する。
※カードは着地マスの市場から獲得し、不足時は山札から引く。

### 港
木箱のカードを捨て札にし、その木箱に塩を獲得する（2箱同時可）。
* 基本点：カードの塩アイコン合計
* 役ボーナス：セット（同数字3枚）なら +2塩
* 大箱ボーナス：大箱なら +3塩
* 流行判定：山札を1枚めくる（手番に1回）。出荷品と同数字が含まれれば +2塩。めくったカードは捨てる。
       
## 5. ゲーム終了
* 終了条件：誰かの手元の塩が20個以上に達した手番。
* 最終手番：スタートプレイヤーの右隣まで手番を行い終了。
* 最終精算：木箱に残った塩は、全木箱の合計2個につき手元の塩1個に換算する。
   （図：残った塩の精算例／合計5塩 ➜ 手元の塩2個）
* 最多得点者の勝利（同点は同着）。
